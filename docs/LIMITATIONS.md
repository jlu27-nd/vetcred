# MVP limits and verification boundaries

- The initial preview retains Vercel SSO protection. A shared portfolio needs no VetCred account, but an outside visitor still needs deployment access until the owner approves public preview access. Scoped automated access is distinct from an unrestricted public-sharing test.

- The prototype uses seeded accounts and server-provisioned cases. Invitations, self-service enrollment, counselor-assignment administration, password recovery and OAuth sign-in are not complete product flows. Email/password sessions are the implemented authentication path.
- Text extraction supports text-based PDF, DOCX and UTF-8 TXT. There is no OCR, handwriting recognition or password-protected document processing. Unreadable/empty extraction fails with a manual text alternative. PDF processing is limited to 30 pages; extracted text to 80,000 characters and 1,000 segments.
- Upload caps are 10 MiB per photo, 8 MiB per document and 24 MiB per audio file. The case upload quota is 40 source records. Supported audio formats are MP3, M4A/MP4, MPEG/MPGA, WAV and WebM. Browser recording availability depends on permissions and MIME support. Other formats need conversion outside VetCred.
- A stored processing job is awaited within a bounded HTTP request. There is no independently scheduled worker: after a terminated request, retry after its four-minute lease expires. Requests have at most four attempts and a case-level processing budget. Provider timeouts, credits and availability can still cause retryable failures.
- AI outputs are schema-validated suggestions with case-scoped references, not factual verification. Human review remains necessary for meaning, source quality, conflicting dates and accidental overstatement. Images do not prove identity, deployments, rank, competence or measurable outcomes.
- Fixture mode uses a fictional person, synthetic resume, synthetic illustrations and generated narration. Sample transcription/writing is explicitly labeled. A working sample is not evidence that live providers work. Sample mode also requires Supabase services.
- Removal hides a source from the working portfolio; immutable evidence and stored files may remain. Sample reset revokes old share links and opens a fresh isolated session; it does not purge prior sample users, database rows or objects. Automated retention, account deletion and orphan-object cleanup need a later operational policy and implementation.
- Sharing uses a frozen snapshot and revocable random token. Raw originals, transcripts, feedback and private sources are excluded. Revocation stops future requests, including photo requests; saved files, screenshots and previously printed PDFs cannot be recalled.
- PDF export uses the browser's print/save-to-PDF view. There is no separate server PDF renderer, document-signing workflow or credential-verification integration.
- The included RLS integration tests exercise the actual isolated preview database. AI schema/unit tests mock provider responses. Three opt-in Playwright live journey checks passed locally against real services. Local success and deployed-preview verification are separate evidence categories, recorded in [VERIFICATION.md](VERIFICATION.md). A successful build or model-catalog lookup does not establish live workflow success.
- TypeScript 6.0.3 and ESLint 9.39.2 are intentionally pinned for compatibility with the installed Next.js ESLint tooling. Do not blindly upgrade the complete toolchain without checking peer dependencies and rerunning all checks.
- The production build explicitly uses Webpack because the Turbopack CSS worker failed in the implementation's Windows environment. The successful Webpack build is the supported build command for this delivery.
- This MVP is not presented as HIPAA, FERPA, SOC 2, FedRAMP or DoD certified/authorized. It does not award credit, determine clinical scope or job eligibility, grant licensure, or make hiring decisions. Job boards, automated applications, billing, employer matching and theme marketplaces are outside this delivery.
- Production promotion, production database provisioning, production monitoring/alerting, retention operations and a full independent penetration/accessibility assessment remain separate work.
